# Historical experimental TOPSPIN artifacts

Every file in this directory is a **historical experimental / retrospective**
artifact produced before the audited paper-reference profile was frozen.  The
data were inspected during development; the `test`/`held-out` labels embedded
in old CSV/Markdown files mean only the historical manifest partition and do
not make these results confirmatory.  They are not eligible for paper
comparison and must not be presented as outputs of the current reference
implementation.

The files are retained only for provenance and regression archaeology.  A
current run must write its own `method_profile`, `evaluation_classification`,
`paper_comparison_eligible`, code identity, and protocol fingerprint.
