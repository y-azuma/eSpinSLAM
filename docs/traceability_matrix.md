# eSpinSLAM paper traceability matrix

Status: **Gate 0 decisions frozen; Gate C solver-equivalence evidence appended**  
Paper: Elms, Latif, and Chin, *Event-based Spinning Object SLAM*, ICCVW 2025  
Decision policy: see [`decision_log.md`](decision_log.md)

Cited-source audit used by the evidence hierarchy: Elms et al.,
[*Event-based Structure-from-Orbit*](https://arxiv.org/abs/2405.06216),
arXiv:2405.06216 / CVPR 2024 (eSfO), especially Secs. 4.1-4.2 and Table 2.
An offline-verifiable evidence map, short source fragments, and source PDF hash
are in [`cited_source_audit.md`](cited_source_audit.md).
eSpinSLAM states that its online front-end adapts this eSfO front-end; the
cited source therefore resolves details that eSpinSLAM does not restate,
except where online chunking changes the problem.

This matrix separates what the paper specifies from what must be interpreted.
It is not a claim that the current code already satisfies every row. Code and
validation columns name the intended implementation and acceptance evidence.

Status vocabulary:

- **Exact**: the paper provides enough detail to implement the stated behavior.
- **Ambiguous**: the paper states the operation but omits a consequential detail.
- **Not-stated**: the behavior or safeguard does not appear in the paper.
- **Unavailable**: the published TOPSPIN release lacks data needed to reproduce
  the paper's metric.

## Reproduction boundary

The reference result must not include a harmonic guard, overlap-restricted
Eq. (9), the 15%-near-best shortest-period rule, parallax filtering, terminal
offline BA, or a "safe" backend. These can appear only under **Future Work /
experimental interpretations**, never in paper-comparison tables. Exact
implementation accelerations are allowed only after equivalence with the
brute-force/reference computation is demonstrated.
